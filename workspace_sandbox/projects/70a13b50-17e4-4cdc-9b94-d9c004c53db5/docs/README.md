# Calculator API
## Overview
The Calculator API is a simple API that provides basic calculator operations.

## Endpoints
### Root Endpoint
GET /
Returns a JSON response with a message indicating that the Calculator API is running.

### Add Endpoint
GET /add/<num1>/<num2>
Returns a JSON response with the sum of num1 and num2.
