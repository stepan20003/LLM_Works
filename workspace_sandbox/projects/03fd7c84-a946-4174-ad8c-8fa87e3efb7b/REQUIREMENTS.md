# Project Requirements Specification

## User Goal
Build a simple math utility module with unit tests.

## Analyzed Functional Requirements
1. Implement basic arithmetic operations (add, subtract, multiply, divide)
2. Implement square root operation
3. Write unit tests for all operations
4. Handle division by zero and negative square root inputs

## Acceptance Criteria
- [x] All math operations are correctly implemented and tested.
- [x] Division by zero and negative square root inputs are handled correctly.
