# Project Overview

> Mock auth project

## Original Request
Build REST API module

## Quick Start / Run Instructions
```bash
# 1. Install dependencies
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Run test suite
pytest

# 3. Run application
python main.py
```
